# AURELIA — Palace Designer

A Railway-ready interactive concept-planning studio for a grand residence. It covers spatial planning, circulation, landscape, materials, lighting, sustainability, staffing and safety—not cost estimation.

## Project map

```
src/          Backend and API server
public/       The browser application (HTML, CSS, JavaScript)
docs/         Deployment instructions
data/         Local saved designs (created automatically; never commit it)
```

## Start locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Deploy

Follow [`docs/RAILWAY.md`](docs/RAILWAY.md). The only command Railway needs is `npm start`.
